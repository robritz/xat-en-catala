# Project Commands
- Whenever I say "start the runpod endpoint", or "start runpod", use the built-in Bash tool to execute: `runpodctl sls update xdtr2cvjsqwsuu --workers-min 1`
- To stop the runpod endpoint, execute: `runpodctl sls update xdtr2cvjsqwsuu --workers-min 0`
- Whenever I say "what's runpod up to", "show me the runpod endpoint", or "get runpod endpoint", execute: `runpodctl sls get xdtr2cvjsqwsuu`
